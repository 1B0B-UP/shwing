# Shwing

Ear training app with spaced-repetition drills for musicians.

## Features

- **Anchors** — build a personal library of song-based memory anchors for notes, intervals, chords, and keys. Tie each one to a real song you know.
- **Drills** — SM2 spaced-repetition flashcard sessions that surface cards based on your recall history
- **Progress** — track accuracy over time, see weak spots, and monitor your streak

## Stack

- Next.js, React, Tailwind v4
- SQLite (via node:sqlite)

## Run locally

```bash
npm install
npm run dev
```

Runs on [http://localhost:4000](http://localhost:4000).
